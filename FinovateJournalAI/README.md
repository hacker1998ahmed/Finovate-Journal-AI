# Finovate Journal AI

## برنامج محاسبي ذكي لسطح المكتب

**Finovate Journal AI** هو تطبيق محاسبي احترافي يعمل على Windows، مصمم لتحويل العمليات المحاسبية المكتوبة باللغة الطبيعية إلى قيود يومية محاسبية قابلة للمراجعة والاعتماد.

### المميزات الرئيسية

- 🧠 **القيد الذكي**: تحليل النصوص العربية والإنجليزية باستخدام NLP
- 📊 **محرك محاسبي متكامل**: دليل حسابات، دفتر يومية، دفتر أستاذ، ميزان مراجعة
- 💰 **إدارة الضرائب**: دعم ضريبة القيمة المضافة (VAT) بنسبة 14%
- 👥 **العملاء والموردين**: إدارة كاملة للحسابات المدينة والدائنة
- 🏦 **الصندوق والبنوك**: متابعة أرصدة النقدية والبنكية
- 📈 **التقارير المالية**: تقارير Excel وPDF احترافية
- 🌐 **ثنائي اللغة**: واجهة عربية/إنجليزية مع دعم RTL
- 🔒 **الأمان**: صلاحيات مستخدمين، سجل تدقيق، تشفير كلمات المرور
- 🤖 **الذكاء الاصطناعي**: دعم اختياري لمزودي AI المحليين والسحابيين

### البنية التقنية

- **Python 3.12+**
- **PySide6** للواجهة
- **SQLite + SQLAlchemy** لقاعدة البيانات
- **Pydantic** للتحقق من البيانات
- **openpyxl** لملفات Excel
- **reportlab** لتقارير PDF
